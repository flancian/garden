# flan.agor.ai

- An [[instance]] of the [[Agora]].
  - A living [[digital twin]] of [[anagora.org]].
  - Hosted on [[hypatia]] using the [[agora recipe]] under [[coop cloud]] and [[traefik]].
  - Regularized using [[podman]] and [[docker compose]] with [[uv]].
- **Mission**:
  - Achieve **zero diffs / no delta** with respect to [[anagora.org]] over time.
  - Eliminate "snowflake server" drift on [[thecla]].
  - Provide a safe canary for testing [[activitypub]], bot bridges, and protocol updates.
